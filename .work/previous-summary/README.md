# AI 디자인 작업 요약

[HTML 요약](clone/how-to-turn-your-ai-into-a-world/index.html)과 [슬라이드 노트](slide-notes.md)를 담았습니다. 원문 전체와 원본 이미지를 복제한 자료는 아닙니다.

원문: Anshu Chimala, [How to turn your AI into a world-class designer](https://www.lennysnewsletter.com/p/how-to-turn-your-ai-into-a-world), Lenny’s Newsletter, 2026년 9월 1일.

공개된 내용을 세 파트로 나누어 짧게 요약했습니다. 원문은 일곱 번째 기법의 제목 다음에 유료 구독 안내가 나오므로, 그 뒤의 본문은 확인하지 않았습니다.

슬라이드 노트는 파트마다 제목, 본문, 참고 도해 하나로 구성했습니다. 제목은 명사로 끝나며, 본문은 완성된 문장으로 썼습니다. 도해 세 장은 내용을 설명하기 위해 새로 그렸고 `assets/`에 저장했습니다. 원본 이미지는 내려받지 않았습니다.

HTML에는 같은 도해를 내장했습니다. HTML 파일 하나만 옮겨도 인터넷 연결 없이 읽을 수 있습니다. 인쇄할 때는 파트마다 페이지가 나뉩니다.

한국어에는 [fluent-korean 작성 지침](https://github.com/snflkd/fluent-korean/blob/main/plugins/fluent-korean/output-styles/fluent-korean.md)을 적용했습니다. 전역 설치 없이 지침 전문을 읽고 문장을 검토했습니다. 가운뎃점은 쓰지 않았습니다.
